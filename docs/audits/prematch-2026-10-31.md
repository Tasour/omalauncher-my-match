# Audit avant-match — 2026-10-31

Trois audits experts en lecture seule : UX/UI, accessibilité mobile, données.
Décisions appliquées dans **v5.17.3**.

## UX / hiérarchie

- Les tendances doivent précéder les détails ; la page actuelle reste longue.
- Doublons : projection, cotes, H2H, forme, buts/clean sheets.
- Hero trop haut, chrome dupliqué (fermer/copier + X système).
- Barres à zéro trompeuses (`0 vs 0` = 50/50).
- Compos/actus non fiables ou vides.

**Appliqué** : projection retirée, points réels à la place ; leaders vides masqués ;
actus filtrées sur les noms des deux équipes (plus de faux positifs sur les sigles).
**Différé** : refonte en onglets Aperçu/Détails, hero compact, barres zéro exactes,
suppression des sections dupliquées.

## Accessibilité / ergonomie

- Graphiques sans alternative textuelle ; cibles < 48 dp ; textes < 12 sp.
- Couleurs d'équipe parfois sombres ; information par couleur seule.
- Troncatures `maxLines:1` ; ordre TalkBack ; pas d'en-tête sticky.

**Appliqué** : états vides explicites pour compos/actus ; données vides non affichées.
**Différé** : refonte typographique, cibles 48 dp, mode daltonien sur toutes les
barres/chips, libellés TalkBack, en-tête sticky.

## Données

- Leaders ESPN vides à cause d'une extraction trop haute ; masqués.
- News de ligue non liées au match ; filtre par noms complets.
- Stats boxscore parfois contradictoires avec le classement ; à ne pas afficher avant match.
- H2H faux si ESPN omet `winner` ; à recalculer depuis les scores.
- Projection PPG×38 fausse pour 34 matchs/coupes ; supprimée.
- Forme dupliquée/ordre incohérent ; déduplication et même compétition à faire.

**Appliqué** : projection supprimée, leaders vides masqués, news liées, compos publiées seulement.
**Différé** : recalcul H2H depuis les scores, déduplication de forme, fraîcheur par bloc.

## Critères pour la refonte complète

- Tendances au-dessus de la ligne de flottaison sur 1080×2186.
- Une seule occurrence par métrique dans l'aperçu.
- 0 barre pour une valeur nulle ; valeurs et unités toujours textuelles.
- 0 texte < 12 sp ; 100 % des actions ≥48 dp.
- Actus liées, compos uniquement si publiées, états vides explicites.
